# Activity Heatmap – Übersicht-виджет

> **Это прототип** – первая версия, с которой всё начиналось. Основная версия –
> самостоятельное приложение без Übersicht: [../native/README.md](../native/README.md).
>
> Прототип продолжает работать сам по себе, нативное приложение от него не зависит.
> Всё, что описано ниже, относится только к нему.

GitHub-style heatmap активности мака за последние 13 недель. Данные – из macOS Screen Time
(`knowledgeC.db`), агрегация – Python-скрипт без внешних зависимостей.

## Состав

| Файл | Назначение |
|---|---|
| `activity-heatmap.widget/aggregate.py` | Читает `knowledgeC.db`, агрегирует по дням, копит историю в `activity.json` и печатает JSON в stdout |
| `activity-heatmap.widget/config.json` | Allow/deny списки, человекочитаемые имена и тема (акцентный цвет, размер клетки, легенда) |
| `activity-heatmap.widget/activity.json` | Накопленная история (создаётся при первом запуске) |
| `activity-heatmap.widget/index.jsx` | Сам виджет: сетка 7×13, ramp из 5 уровней на базе `#9974f7`, hover-тултип |

## Установка

> Всё перечисленное ниже уже сделано на этой машине 19.07.2026 – раздел нужен для
> переустановки или для второго мака.

1. **Übersicht**: <https://tracesof.net/uebersicht/> (или `brew install --cask ubersicht`),
   запустить хотя бы раз – первый запуск создаёт папку `widgets/`.

2. Скопируй папку виджета (из этой директории, `ubersicht-prototype/`):

   ```sh
   cp -R "activity-heatmap.widget" ~/Library/Application\ Support/Übersicht/widgets/
   ```

   ⚠️ Имя папки `activity-heatmap.widget` менять нельзя – оно зашито в `command` внутри
   `index.jsx` (Übersicht запускает команды из корня `widgets/`). Переименуешь папку –
   поправь и строку `command`.

3. **Full Disk Access** – без него база не читается. System Settings → Privacy & Security →
   Full Disk Access → «+» → добавь **Übersicht** → перезапусти приложение.
   Пока доступа нет, виджет вместо сетки покажет эту же инструкцию.

4. Обнови виджеты в меню Übersicht – heatmap появится в левом верхнем углу.

## Настройка

**Фильтр** – `config.json`:

- `"mode": "deny"` (по умолчанию) – считаем всё, кроме перечисленного в `deny`. Работает
  сразу, отсекает системный шум (Finder, loginwindow, скринсейвер).
- `"mode": "allow"` – считаем **только** то, что перечислено в `allow`. Переключись, если
  хочешь трекать конкретный набор рабочих приложений.
- `apps` – bundle id (`md.obsidian`), `sites` – домены (`github.com`).
- `names` – человекочитаемые подписи для тултипа, работают и для bundle id, и для доменов;
  без записи имя берётся из последнего сегмента bundle id (`com.apple.Safari` → `Safari`),
  что для некоторых даёт уродливое `claudefordesktop` – такие лучше прописать руками.
- `minSeconds` – дни короче этого порога считаются пустыми.

Узнать bundle id приложения: `osascript -e 'id of app "Obsidian"'`.

Список уже заполнен под твой реальный набор приложений (Claude, Obsidian, Telegram, VLC,
Terminal, LocalSend, Телемост и т.д.). В `sites.deny` добавлен `desktop.docker.com` –
закреплённая вкладка, накрутившая 46 ч за неделю.

**Цвета** – секция `theme` в `config.json`:

```json
"theme": { "accent": "#9974f7", "showLegend": true, "cellSize": 22 }
```

- `accent` – **любой** hex (`#rgb` или `#rrggbb`). Рампа из 5 оттенков строится
  автоматически, руками её задавать не нужно.
- `showLegend` – нижняя строка «Меньше ▪▪▪▪▪ Больше» и суммарное время.
- `cellSize` – размер клетки в px; отступ и скругление считаются от него, так что виджет
  масштабируется целиком.
- `ramp` – необязательный массив из 5 hex. Если задан, перебивает генерацию из `accent`
  целиком (на случай, если хочется совсем свою палитру).

Как строится рампа: акцент переводится в OKLCH, из него берётся **hue**, и по этому тону
проходит фиксированная кривая светлоты и насыщенности
(`L = .95 .86 .75 .62 .48`, `C = .025 .09 .13 .14 .12`). OKLCH нужен потому, что даёт
перцептивно равные шаги – в отличие от простого изменения прозрачности одного цвета,
где средние ступени визуально слипаются. Результат отдаётся виджету уже в sRGB hex,
поэтому поддержка CSS `oklch()` в WebKit не требуется.

Ахроматичный акцент (`#000`, `#fff`, `#808080`) даёт нейтрально-серую рампу, а не случайный
тон: у серого нет осмысленного hue. Битый `accent` откатывается на `#9974f7`.

Правки в `config.json` подхватываются при следующем запуске скрипта – чтобы увидеть сразу,
сделай `touch` по `index.jsx`.

**Частота обновления** – `refreshFrequency` в `index.jsx`, сейчас раз в час
(`60 * 60 * 1000`). Реже: `24 * 60 * 60 * 1000` – раз в сутки. Чаще часа смысла мало,
чтение базы не бесплатное.

## Перемещение виджета

Übersicht не умеет двигать виджеты – позиция зашита в CSS. Поэтому перетаскивание
встроено в сам виджет:

- **Тяни за шапку** (строка «Активность» с пилюлей) – курсор там меняется на «руку».
  Клетки сетки остаются кликабельными для тултипа, тянуть за них нельзя специально.
- **Двойной клик по шапке** – вернуть в исходную точку.
- Позиция сохраняется в `position.json` рядом с виджетом и переживает перезапуск
  Übersicht и обновление данных. Это просто `{"x":-320,"y":118}` – смещение от базовой
  точки, можно править руками.
- Базовая точка (куда возвращает двойной клик) – `top` / `left` в начале `className`
  в `index.jsx`, сейчас 40/40 от левого верхнего угла.

Удалить `position.json` – то же самое, что двойной клик.

## Как считается время

- **Итог за день** = объединение (union) интервалов `/app/usage`, пересечённое с периодами,
  когда экран **не заблокирован** (`/device/isLocked`). Без вычета блокировки всегда
  включённый мак даёт ровно 24 ч каждый день и heatmap теряет контраст.
- **Только foreground.** `/app/webUsage` тикает и для фоновых вкладок: закреплённая вкладка
  `desktop.docker.com` накрутила 46 ч за 6 дней. Поэтому домен засчитывается лишь на
  пересечении со временем, когда его браузер был на переднем плане, а сам общий итог дня
  считается по `/app/usage`.
- **Домен вместо браузера.** В `/app/webUsage` поле `ZVALUESTRING` содержит bundle id
  браузера, а не домен – настоящий домен берётся джойном на
  `ZSTRUCTUREDMETADATA.Z_DKDIGITALHEALTHMETADATAKEY__WEBDOMAIN`. Safari отдельной строкой в
  топ-3 не выводится, вместо него идут его домены – иначе время задваивалось бы.
- Интервалы через полночь режутся по локальным суткам и попадают в оба дня.
- Интенсивность клетки – квартили по непустым дням, так что ramp подстраивается под твой
  реальный режим, а не под абсолютную шкалу.

## Накопление истории (важно)

macOS чистит `knowledgeC.db` очень быстро – на этой машине в базе лежало всего **6 дней**
(13–19 июля). Сетка на 13 недель из одной только базы не заполнится никогда.

Поэтому `aggregate.py` ведёт собственную историю: при каждом запуске он мержит свежие дни
из базы в `activity.json` и хранит их 91 день. Дни, которые ещё есть в базе,
перезаписываются (они могли дорасти), более старые доживают в JSON, пока не выпадут из окна.

Отсюда два следствия:

- **`activity.json` – единственная копия старых дней.** Не удаляй его: то, что macOS уже
  вычистил из базы, восстановить неоткуда. При сбое (нет доступа, ошибка) скрипт намеренно
  **не** перезаписывает файл, чтобы не потерять историю; запись атомарная через `.tmp` +
  `os.replace`.
- Сетка будет заполняться постепенно – первые недели правая часть heatmap живая, а левая
  пустая. Это нормально.

Хочешь бэкапить историю – просто копируй `activity.json`.

## Проверка

Смотреть надо на файл, который пишет **сам виджет**:

```sh
python3 -m json.tool ~/Library/Application\ Support/Übersicht/widgets/activity-heatmap.widget/activity.json
```

Запуск `python3 aggregate.py` из обычного терминала почти наверняка вернёт
`{"error": "no_access"}` – и это **не** признак поломки: Full Disk Access выдаётся
конкретному приложению, у Übersicht он есть, у Terminal – нет.

Заставить виджет перечитать данные: `touch` по `index.jsx` (Übersicht следит за файлами)
либо «Refresh all widgets» в меню.

Если после выдачи FDA всё равно `no_access` – приложение нужно **полностью перезапустить**:
процесс, стартовавший до выдачи прав, их не подхватывает. `quit` через AppleScript на
Übersicht не действует, надёжнее убить процесс:

```sh
pkill -f 'Übersicht.app/Contents/MacOS' ; open -a "Übersicht"
```
